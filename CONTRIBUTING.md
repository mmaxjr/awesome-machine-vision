# Contributing

Thanks for helping improve Awesome Machine Vision.

## What belongs here

This repository focuses on practical computer vision and machine vision systems:

- object detection
- segmentation
- tracking
- OCR
- industrial inspection
- agriculture and environmental monitoring
- fire and smoke detection
- edge AI deployment
- camera pipelines
- production monitoring
- datasets and annotation tools

## Link quality

Please prefer links that are:

- actively maintained, or still historically important
- documented enough for someone to use
- relevant to production or applied computer vision
- not just a marketing page with no technical value

## Format

Use this format:

```markdown
- [Project Name](https://example.com) - Short description.
```

Keep descriptions neutral and useful. Avoid hype words.

## Pull requests

Small pull requests are best. If you are adding many links, group them by section.

## Review checklist

Before opening a pull request, please check that:

- the link works and points to the primary project, docs, paper, or dataset
- the description explains the practical value in one sentence
- the item is placed in the most specific section available
- the entry does not duplicate an existing resource
- commercial tools are clearly useful for machine vision work
- production notes are based on practical deployment concerns, not hype

For new sections, include a short introduction that explains when someone would use that category.
